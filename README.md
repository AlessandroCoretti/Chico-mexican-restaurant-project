# HOLA CHICOS 🌮

Meet CHICOS, a restaurant specializing in Mexican cuisine that is… nowhere to be found!!
Yeah, I invented it from scratch, but I'm sure it would be super good and super beautiful if it actually existed.

The project was created entirely with React and TailwindCSS.
I created the logos, the lyrics and everything else, just to give the idea of a complete and properly made brand.

I'm using this as a description of a little project I'm uploading here to GitHub, more for fun than anything else but hey, maybe one day CHICOS becomes a reality!
